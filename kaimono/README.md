# ひと呼吸 — 買う前のクールダウン

衝動買いをへらすためのアプリです。欲しくなったものを**いったん「あずける」**→ 決められた時間が過ぎてから、**買うかどうかを改めて決める**という流れになっています。やめておいた分は「がまん貯金」としてたまっていきます。

公開URL: https://noel-ist8985.github.io/airline-deals/kaimono/

## つかい方

1. 下の「＋ 欲しいものを預ける」を押して、品名・金額などを入れる
2. 金額に応じて「あずける時間」が自動で決まる（変更もできます）
3. 時間が過ぎると「決める」タブに出てくる
4. あずけた時に自分が書いた理由を読み返して、「やめておく」か「買う」を選ぶ
5. やめた分は「がまん貯金」に、買った分は今月の予算バーに反映される

## あずける時間のめやす（設定で変更できます）

| 金額 | あずける時間 |
| --- | --- |
| 〜3,000円 | 1日 |
| 〜10,000円 | 3日 |
| 〜30,000円 | 1週間 |
| 〜100,000円 | 2週間 |
| 100,000円〜 | 1ヶ月 |

- 「必要なもの」を選ぶと **半分** の時間になります
- 衝動のサイン（同じ物を持っている／セールに押されている など）に3つ以上チェックが付くと **2倍** になります

## 貯金の目標

貯金カードの「🎯 貯金の目標を決める」、または「記録」タブから設定します。

- 目標の名前と金額を決めると、やめるたびにその目標へ積み上がります
- 目標を作るときに、**いまの貯金をあてる／とっておく**が選べます
- 目標に届いたら「この目標に使う（貯金からおろす）」で達成にします。貯金から目標金額が引かれ、あまった分は次の目標に引きつがれます
- 達成した目標は「🏅 達成した目標」に残ります

## 気晴らしの提案

画面の下の「🫧 気晴らし」から使います。ストレスによる衝動買いの逃げ道です。

1. いまの気分を選ぶ（イライラする／疲れた／さみしい／退屈／不安・もやもや／とにかく買いたい）
2. その気分に合う案が3つ出る（所要時間つき）。「ほかの案を見る」で入れ替えられます
3. ひとつ選んで「やってみた！」を押すと、気晴らしの記録に1回たされます

登録画面で「疲れている／気分を変えたくて見ている」にチェックを付けると、その場にも「先に気晴らしを試してみる」ボタンが出ます。提案の文言は `index.html` の `IDEAS` にまとまっているので、自分に効くものへ自由に書き換えられます。

## しくみ

- `index.html` 1枚だけで動きます（CSSもJavaScriptもこの中に入っています）
- 記録は**その端末のブラウザの中だけ**に保存されます（localStorage）。サーバーには何も送りません
- 端末を替えるときや、ブラウザのデータを消す前に、⚙ の「バックアップを書き出す」でファイルに保存しておいてください
- `sw.js` と `manifest.webmanifest` はホーム画面に追加して使うための設定です（圏外でも開けます）
