# オタクイベントまとめ

日本の**同人イベント・アニメイベント・キャンペーン**の情報を、毎日自動で集めてまとめて表示するアプリです。

公開URL（GitHubにpushしたあと使えます）
👉 **https://noel-ist8985.github.io/airline-deals/events/**

---

## 1. できること

| 機能 | 説明 |
| --- | --- |
| 3つのカテゴリ | 同人イベント / アニメイベント / キャンペーン に自動で仕分け |
| キーワード検索 | 作品名・イベント名・会場名で絞り込み（例：「呪術廻戦」で85件） |
| 開催地で絞り込み | 地方（関東・近畿…）または都道府県ごと |
| 期間で絞り込み | 今日 / 今週末 / 1週間以内 / 今月 / 来月 |
| **締切間近だけ** | サークル参加の申込締切が14日以内のイベントだけを表示 |
| 並び替え | 開催日が近い順 / 申込締切が近い順 / 新着順 |
| ★保存 | 気になるイベントを端末に保存（お使いの端末内だけに残ります） |
| ホーム画面に追加 | スマホのホーム画面に置いてアプリのように使えます |
| オフライン表示 | 電波が無くても、前回開いた内容を表示できます |

| 取得元 | 取れる情報 |

| [ケットコム](https://ketto.com/) | オンリーイベントの開催日・会場・時間・ジャンル |
| [コミックナタリー](https://natalie.mu/comic) | アニメ・マンガのイベント / キャンペーンニュース |
| [音楽ナタリー](https://natalie.mu/music) | アニソン・声優ライブなど |
| [ステージナタリー](https://natalie.mu/stage) | 2.5次元舞台・ミュージカル |
| [アニメ！アニメ！](https://animeanime.jp/) | アニメイベント・コラボ・グッズ情報 |
| [おたくま経済新聞](https://otakuma.net/) | オタク系の話題全般 |

## 3. 自動更新のしくみ

GitHub Actions が **毎日 朝7時と夜7時（日本時間）** に自動で動きます。

```
情報源のサイト・RSS
      ↓  events/scripts/fetch_events.py が取得・整理
events/data/events.json  ← 自動でコミットされる
      ↓
アプリ画面（events/index.html）が読み込んで表示
```

前回集めた情報も引き継がれるので、動かすたびに情報が積み上がっていきます。
終わったイベントは、開催日から3日過ぎると自動で一覧から消えます。

### 手動で今すぐ更新したいとき

1. GitHubでこのリポジトリを開く
2. 上の **「Actions」** タブをクリック
3. 左のリストから **「イベント情報の自動更新」** をクリック
4. 右にある **「Run workflow」** ボタン → もう一度 **「Run workflow」** をクリック
5. 1〜2分待つと、最新の情報に入れ替わります

## 4. 自分でイベントを追加したいとき

自動で拾えなかったイベントは、`events/data/manual.json` に手で書き足せます。

`"events": []` の `[ ]` の中に、次のようなかたまりを書きます（複数書くときはカンマ区切り）。

```json
{
  "category": "doujin",
  "title": "コミックマーケット 109",
  "summary": "オールジャンル同人誌即売会",
  "url": "https://www.comiket.co.jp/",
  "start_date": "2026-12-30",
  "end_date": "2026-12-31",
  "venue": "東京ビッグサイト",
  "prefecture": "東京",
  "deadline": "2026-08-31",
  "tags": ["オールジャンル", "コミケ"]
}
```

- `category` は `doujin`（同人イベント）/ `anime_event`（アニメイベント）/ `campaign`（キャンペーン）のどれか
- 日付は `"2026-12-31"` の形で書く
- 分からない項目は、その行ごと消してOK

書き足したら保存 → pushすると、次の自動更新で一覧に出てきます。

## 5. 情報源を増やす・減らす

`events/scripts/sources.json` を編集します。

- 一時的に止めたい → その情報源の `"enabled": true` を `false` に変える
- RSSを追加したい → `"feeds"` の中に、同じ形でひとかたまり書き足す

```json
{
  "id": "example",
  "name": "サイト名",
  "kind": "feed",
  "enabled": true,
  "url": "https://example.com/feed"
}
```

---

## 6. 手元のパソコンで動かす（任意）

追加インストールは不要です（Pythonの標準機能だけで動きます）。

```bash
python3 events/scripts/fetch_events.py
```

## ファイル構成

```
events/
├── index.html                  画面
├── css/styles.css              見た目
├── js/app.js                   絞り込み・並び替え・表示の処理
├── manifest.webmanifest        ホーム画面に追加するための設定
├── sw.js                       オフライン表示の処理
├── icons/                      アプリのアイコン
├── data/
│   ├── events.json             自動生成される一覧（さわらなくてOK）
│   └── manual.json             手で追加したいイベント
└── scripts/
    ├── fetch_events.py         情報を集めるプログラム
    └── sources.json            情報源の一覧

.github/workflows/update-events.yml   1日2回の自動更新の設定
```
